# social-videos

Hosting for the short videos of the **Claude Game Arena** browser games: one song reel per game for Instagram
Reels, TikTok and YouTube Shorts. This repository holds no source code, only the finished video files, so the
post scheduler gets a stable public URL for each one.

> [!NOTE]
> **The songs and voices in these videos are AI-generated** (the songs with Google Flow Music, older voiceovers
> with Google Gemini TTS and Supertonic 3). Every post that uses one of these videos says so too.

## Game song reels (`2026-11/`)

Each of the 21 games has one vertical song reel of about 35 to 45 seconds that teaches a few Turkish words through
the game. The files sit in the `2026-11/` folder, named `<publish-date>-<game>-telefon.mp4` (or
`<publish-date>-sarki-<game>.mp4` for the first batch). A file URL looks like:

```
https://raw.githubusercontent.com/Furkiozknn/social-videos/master/2026-11/2026-11-21-ebru-telefon.mp4
```

## Older releases

The [Releases](../../releases) page keeps the earlier videos: the October and November 2026 game promos
(`promo-2026-10`, `promo-2026-11`), the Fay Hattı devlog (`devlog-2026-11`) and the Built with Claude Code
episodes (`ep21-27`, `ep28-plus`). No new files are added to them.

## The games

All 21 games run in the browser on desktop and phone, with nothing to install. The full list is on
[furkiozknn.github.io](https://furkiozknn.github.io/).
