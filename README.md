# social-videos

Hosting for the short videos of the **Built with Claude Code** series (YouTube Shorts, Instagram Reels and Stories, X).
Video files live in [Releases](../../releases), one release per batch of episodes, so they have stable public download URLs for the scheduler.

Voiceover in these videos is AI-generated (Supertonic 3). Made with Remotion in [video-studio](https://github.com/Furkiozknn).
